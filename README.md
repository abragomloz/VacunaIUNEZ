VacunaPC

Herramienta de detección y desinfección heurística diseñada para identificar posibles infecciones en dispositivos de almacenamiento extraíble y equipos Windows.
La aplicación analiza el sistema en busca de patrones asociados con malware que oculta directorios originales y los suplanta mediante archivos ejecutables con nombres similares. Cuando identifica elementos sospechosos, realiza las siguientes acciones:
Detección heurística: identifica carpetas ocultas y archivos ejecutables que utilizan nombres coincidentes o similares.
Cuarentena: aísla los archivos ejecutables sospechosos para evitar su ejecución accidental.
Restauración de directorios: elimina los atributos de ocultamiento de las carpetas detectadas para recuperar su visibilidad en el Explorador de archivos.

Objetivo: facilitar la detección de infecciones comunes en memorias USB y dispositivos de almacenamiento, así como recuperar la visibilidad de los archivos y directorios afectados.
Nota: VacunaPC utiliza mecanismos heurísticos; por lo tanto, sus detecciones no constituyen una confirmación definitiva de malware. Se recomienda complementar su uso con un antivirus actualizado.
